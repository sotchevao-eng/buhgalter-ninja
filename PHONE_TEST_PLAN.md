# План теста на физических телефонах — Бухгалтер-ниндзя 0.9.0

Пока реальные устройства не прогнаны, все результаты **NOT TESTED**. Не заполнять «плавно» заранее.

Нужны минимум два типа, если доступны: Android и iPhone. Если есть только один тип — отметить ограничение, тест всё равно провести.

Проверять два канала:

1. приложение VK (после появления Mini App и HTTPS);
2. обычный мобильный браузер по production URL (или локальный HTTP, если production URL ещё нет).

## Чеклист на каждом устройстве

- [ ] Загрузка: игра открывается, белого экрана нет
- [ ] Canvas: поле видно, не обрезано странно
- [ ] Touch: стрелки ◀ ▶ нажимаются
- [ ] Удержание кнопок работает
- [ ] Safe area: кнопки не под вырезом / домашней полосой
- [ ] Можно сыграть партию
- [ ] Пауза работает
- [ ] Сворачивание приложения ставит паузу
- [ ] Звук появляется после первого нажатия
- [ ] Game Over помещается на экран
- [ ] Share или копирование результата
- [ ] Профиль помещается
- [ ] Рейтинг читается

Производительность отметить одним словом: Плавно / Допустимо / Есть торможения.
