# BUG_AUDIT — Бухгалтер-ниндзя 0.8.0

Список этапа 8. На 0.9.0 игровая логика не переписывалась; оставшиеся блокеры публикации — в `PRODUCTION_BLOCKERS.md`.

Проверка по промту 8. Git в папке проекта не инициализирован — backup-commit не создавался.

Формат: ID, раздел, описание, критичность, статус, причина, исправление, проверка.

## BUG-001

**Раздел:** Backend / sessions  
**Описание:** Параллельный `POST /game/session/:id/finish` мог дважды начислить XP и статистику: сессия читалась вне транзакции, прогресс обновлялся даже если `UPDATE ... status='started'` затронул 0 строк.  
**Критичность:** Critical  
**Статус:** Fixed  
**Причина:** TOCTOU без `FOR UPDATE` и без проверки `rowCount`.  
**Исправление:** `SELECT ... FOR UPDATE` внутри транзакции; `RETURNING`; при 0 строк — идемпотентный ответ.  
**Проверка:** код `server/src/routes.js`; unit-тесты идемпотентности `validateFinish`.

## BUG-002

**Раздел:** Backend / daily  
**Описание:** Параллельный `POST /me/daily/claim` мог дважды выдать XP.  
**Критичность:** Critical  
**Статус:** Fixed  
**Причина:** Чтение `reward_claimed` и UPDATE без блокировки строки.  
**Исправление:** `FOR UPDATE` + `RETURNING`; при 0 строк — `ALREADY_CLAIMED`.  
**Проверка:** `server/src/routes.js`.

## BUG-003

**Раздел:** Gameplay / start  
**Описание:** Двойной клик «НАЧАТЬ» после обучения вызывал `startGame()` дважды (`_startLock` не проверялся внутри `startGame`).  
**Критичность:** High  
**Статус:** Fixed  
**Причина:** Замок только на `requestStart` / `restartGame`.  
**Исправление:** Проверка `_startLock` в `startGame`; `finishTutorial` сбрасывает замок один раз.  
**Проверка:** `js/game.js`.

## BUG-006

**Раздел:** Sync / XP  
**Описание:** `applyCloudProgress` затирал локальный XP/уровень серверным, даже если локально было больше (гонка finish vs GET /me).  
**Критичность:** High  
**Статус:** Fixed  
**Причина:** Присвоение `stats.playerXP = progress.xp` без сравнения.  
**Исправление:** Берём облако только если уровень выше или тот же уровень и XP ≥ локального. Рекорды по-прежнему `Math.max`.  
**Проверка:** `js/sync.js`.

## BUG-012

**Раздел:** Validation  
**Описание:** `PUT /me/progress` принимал NaN и любые ID достижений.
