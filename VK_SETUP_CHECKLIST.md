# Чеклист настройки VK Mini Apps — Бухгалтер-ниндзя 0.9.0

Сверяйте названия пунктов кабинета с актуальной документацией. Источники (август 2026):

- https://dev.vk.com/ru/mini-apps/getting-started
- https://dev.vk.com/ru/mini-apps/development/launch-params-sign
- https://dev.vk.com/ru/bridge/overview
- https://dev.vk.com/ru/mini-apps/settings/general/information
- https://dev.vk.com/ru/mini-apps/settings/moderation
- https://dev.vk.com/ru/mini-apps-rules

Тип приложения по официальной инструкции: **Мини-приложение**. Регистрация — в десктопной версии VK / на [dev.vk.com](https://dev.vk.com), пункт создания приложения.

Серверная проверка пользователя в этом проекте: HMAC-SHA256 по отсортированным параметрам `vk_*` и параметру `sign`. Для неё нужен **защищённый ключ** приложения (официально: раздел про ключи доступа). Значение хранится только в `server/.env` как `VK_APP_SECRET`.

Код уже вызывает VK Bridge и `VKWebAppInit`. Переписывать Game Core не требуется.

## Действия

- [ ] Открыть десктопный VK / кабинет приложений и создать приложение типа **Мини-приложение**
- [ ] Скопировать идентификатор приложения (генерируется при создании) → `VK_APP_ID` и `js/runtime-config.js` (`vkAppId`)
- [ ] Указать HTTPS URL игры (после появления домена). Не `localhost`
- [ ] Добавить домен в разрешённые / доверенные, как требует текущий кабинет. Для пользователей `vk.ru` проверить актуальные требования к домену
- [ ] Скопировать защищённый ключ только в `server/.env` → `VK_APP_SECRET` (не во frontend)
- [ ] Перезапустить API и проверить `POST /api/v1/auth/vk` на реальных launch-параметрах
- [ ] Проверить, что frontend вызывает инициализацию Bridge
- [ ] В информации приложения выбрать официальное сообщество / запуск из сообщества (формулировки сверять с кабинетом)
- [ ] Записать `VK_GROUP_ID` и публичный URL сообщества в `runtime-config.js` (`vkGroupId`, `communityUrl`)
- [ ] Открыть приложение из сообщества на десктопе
- [ ] Открыть приложение из приложения VK на телефоне (см. `PHONE_TEST_PLAN.md`)
- [ ] Убедиться, что в обычном браузере без VK остаётся Guest Mode
- [ ] Заполнить `privacy.html` / `terms.html` и отправить на модерацию, если это требуют текущие правила

Значения не придумывать. Пустые поля оставлять пустыми до получения из кабинета.
