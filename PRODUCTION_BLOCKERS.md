# Production blockers — Бухгалтер-ниндзя 0.9.0

Только то, чего реально нет для публикации. Код игры и API для локального теста готовы.

1. **VK_APP_ID** — не заполнен.
2. **VK_GROUP_ID** — не заполнен.
3. **VK production configuration** — нет защищённого ключа в `server/.env` (`VK_APP_SECRET`), нет HTTPS URL в кабинете Mini Apps, нет привязки к сообществу.
4. **FRONTEND production URL** — `FRONTEND_URL` / `appLaunchUrl` пустые.
5. **API production URL** — `API_PUBLIC_URL` / `apiBaseUrl` пустые.
6. **Ручное тестирование на физических смартфонах** — Android и iPhone не прогнаны. См. `PHONE_TEST_PLAN.md`.

Дополнительно для модерации и юридических страниц (игра без этого запускается локально):

7. **Оператор / контакт / дата** в `privacy.html` и `terms.html` всё ещё `[указать оператора]`, `[указать контакт]`, `[указать дату]`.
8. **Иконка приложения в кабинете VK** загружается в кабинете VK, в репозитории файла логотипа сообщества нет. Игра рисует интерфейс без логотипа.

Не являются блокерами этого этапа:

- спрайты `.webp` (Canvas-fallback включён, `playerSpritesEnabled: false`);
- отдельные звуковые файлы (Web Audio synth);
- git-репозиторий (проект можно выложить копированием файлов).
